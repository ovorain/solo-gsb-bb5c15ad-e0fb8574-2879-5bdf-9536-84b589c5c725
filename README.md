# SRT 字幕时间校准 / 片段剪辑 / 双语合成 / 阅读速度修复 / 修订差异对照 / 目标词时间标记 / 字幕遮挡避让 / 字幕章节索引 / 字幕空隙提示编排 / 角色抢话分析 / 术语统一替换工具

一个网页小工具，包含十一个相互独立的功能：

1. **字幕时间校准**：根据若干「原字幕时刻 → 视频实际时刻」锚点，对整份 SRT 字幕做时间校准。
2. **剪辑片段字幕**：输入按原视频时间填写的多个保留区间，预览并下载剪辑后重新拼接时间轴的 SRT。
3. **双语 SRT 合成**：分别提供主轨与译文轨两份 SRT，按时间全局配对后合成为主+译分行的双语 SRT。
4. **阅读速度修复**：设置最大每秒字数与单块最长秒数，按「合并次数最少」的全局规划合并相邻字幕，使每块同时满足速度与时长限制。
5. **SRT 修订差异对照**：分别提供旧版、新版两份 SRT，按保持顺序的全局动态规划对齐字幕，逐组标注未变 / 改词 / 拆分 / 合并 / 删除 / 新增，并提供 UTF-8 CSV 下载。
6. **字幕目标词时间标记**：输入一份 SRT 与逐行目标词，预览每个命中词的原字幕序号与估算时间区间，并下载前后扩展、合并后的区间 CSV。
7. **字幕遮挡避让**：输入 SRT 与若干遮挡区间（起止时刻、上方或下方），用动态规划逐条选择字幕置于上方或下方，预览字幕位置并下载带 `line` 位置标示的 WebVTT。
8. **字幕章节索引**：输入 SRT 与目标 / 最短 / 最长章节时长，只在相邻字幕之间切分，用全局规划使每章跨度落在范围内并尽量贴近目标时长，预览各章起止、条数与首句并下载 UTF-8 CSV 章节索引。
9. **字幕空隙提示编排**：输入一份 SRT 与逐行提示（目标起点、持续毫秒、正文），只在相邻原字幕之间的正时长空隙中放入提示（每个空隙最多一条），用有序全局匹配最大化放入条数并最小化起点偏差，预览已放入位置、偏差与未放入提示，并下载按时间重编号的 SRT。
10. **角色抢话分析**：粘贴每条正文首行带 `[角色名]` 标记的 SRT，先对同一角色的左闭右开时间区间求并集，再按并集边界切分时间轴，仅统计两名及以上角色同时活跃的片段（端点相触不算），预览抢话片段及每名角色独占毫秒数、每对角色共同发言毫秒数，并下载含片段与汇总的 UTF-8 CSV。
11. **术语统一替换**：输入一份 SRT 与逐行术语（`标准词=别名1|别名2`），对每条字幕的原正文一次性查找全部别名（忽略 ASCII 大小写、允许重叠命中），同条字幕的重叠命中用全局规划选择互不重叠的组合（依次最大化被替换的原文字符数、最小化替换次数、采用命中起点序列字典序最小），逐条预览原文、命中位置、采用与舍弃的命中及修订正文，并下载保留原序号与时间的修订 SRT（无命中时也可下载原样内容）。

- 后端：Python + FastAPI
- 前端：原生 HTML/JS 单页（无构建步骤）
- 校准算法：锚点按原时刻排序，相邻锚点间**线性插值**，首尾两端按**最近一段斜率外推**，统一换算每条字幕的起止时间

## 启动

只需一条命令（依赖随容器自动安装）：

```bash
docker compose up --build
```

然后在浏览器打开：

**http://localhost:8000** （端口 `8000`）

停止：`Ctrl+C` 或 `docker compose down`。

> 不使用 Docker 时（需 Python 3.10+，`pip install -r requirements.txt`），
> 也可一条命令在本地启动，同样监听 **8000** 端口：
>
> ```bash
> uvicorn app.main:app --host 0.0.0.0 --port 8000
> ```

## 使用方法

### 功能一：字幕时间校准

1. **字幕内容**：粘贴 SRT 文本，或点击「选择文件」上传 `.srt` 文件（该内容同时供下方剪辑功能使用）。
2. **校准锚点**：至少填写 2 个锚点，格式为 `HH:MM:SS,mmm`：
   - 原时刻：字幕文件中显示的时间
   - 实际时刻：该句在视频中真实出现的时间
3. 点击 **预览校准结果**：表格逐条显示原时间、校准后时间及问题标记。
4. 若锚点校验失败（原时刻重复 / 实际时刻未严格递增 / 时间格式错误），页面会自动进行**异常定位**：
   - 标出建议剔除的最少锚点行，并用保留下来的锚点预览受影响字幕（仅建议，**确认前不改动输入**）；
   - 点击 **确认剔除并继续** 才会删除这些行并按原流程重新预览；点击 **放弃建议** 则原样保留输入；
   - 无法凑出 2 个有效锚点时提示「无法预演」，需手动修正。
5. 全部正常时点击 **导出校准后 SRT** 下载 `calibrated.srt`（保留原序号与正文）。

### 功能二：剪辑片段字幕

1. 在第 1 步粘贴 / 上传**原 SRT**。
2. 在「保留区间」中按**原视频时间**填写 1 个或多个区间（`HH:MM:SS,mmm`），表示要保留的视频片段：
   - 每个区间**起点须早于终点**；区间按起点自动排序，**重叠会报错**；
   - 区间为**左闭右开** `[起点, 终点)`，因此相邻区间端点相触（前段终点 = 后段起点）是允许的。
3. 点击 **预览剪辑结果**，表格显示每条字幕裁剪后的交集时间、拼接后的新时间与正文。
4. 点击 **下载剪辑后 SRT** 得到 `clipped.srt`。

裁剪与时间轴拼接规则：

- 对每条字幕与每个保留区间按**左闭右开**求交集：空交集的字幕直接丢弃；
- 一条字幕跨越多个保留区间时，按区间**拆成多条**输出，每条保留同一正文；
- 每段交集时间**减去该区间起点**，再**加上此前所有保留区间的时长之和**，得到剪辑后连续时间轴上的时间；
- 输出按**新起点排序**并从 1 开始**连续重编号**；
- 所有字幕都与区间无交集时禁止下载（预览会提示保留 0 条）。

### 功能三：双语 SRT 合成

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**双语 SRT 合成**」区块（锚点 `#merge`，与上方校准、剪辑功能相互独立，使用各自的两轨输入框）。

1. 在「主轨」「译文轨」两个输入框中分别**粘贴** SRT 文本，或点击各自的「选择文件」上传 `.srt`。导出时以**主轨时间轴与条数**为准。
2. 点击 **预览配对结果**：逐条显示每条主轨、其配对译文（含各自原序号、时间与交叠毫秒数）以及**未配对译文**清单。
3. 点击 **下载双语 SRT** 得到 `bilingual.srt`。

配对与导出规则：

- 按时间**全局**配对：每条主轨可配 **0～2** 条译文，每条译文**至多使用一次**；仅有**正时长交叠**（端点相触，即前段终点 = 后段起点，不算交叠）才会配对；
- 全局优先**最大化总交叠毫秒数**；总交叠相同时优先**少漏配译文**（已配译文条数最多）；仍相同时，按已配译文**原序号（升序）序列字典序最小**决胜；
- 导出按**主轨时间与顺序从 1 连续编号**；每条主轨块内**先写主轨正文、再分行写各条译文正文**；主轨即使没有任何配对译文也**原样保留**；
- 未配对译文只在预览中列出，不写入导出文件；
- 两轨中任一条字幕出现**空时长**（终点 = 起点）或**起止时间倒置**（终点 < 起点）都会返回错误并指明是哪一轨第几条。

实现上复用同一套 SRT 解析（`parse_srt`）与时间工具（`parse_time` / `fmt_time`）。当两轨条目都按 `(起点, 终点)` 非降排列（正常 SRT 时间轴）时用带状保序动态规划求解，典型同片源两轨近线性完成；轨内条目时间回缩（相互包含 / 错位）时自动回退到最小费用最大流，对含交叉的配对仍保证上述全局最优。

### 功能四：阅读速度修复

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**阅读速度修复**」区块（锚点 `#speed`，与上方三个功能相互独立，使用自己的输入框）。

1. **粘贴** SRT 文本或点击「选择文件」上传 `.srt`。
2. 设置两个限速参数（均为**正数**）：
   - **最大每秒字数**：每块允许的最高阅读速度（非空白字符数 / 块起止跨度秒数）；
   - **单块最长秒数**：每块起止跨度（首条起点 → 末条终点）的上限。
3. 点击 **预览修复方案**：表格逐块显示新序号、来源序号（原 SRT 序号）、时间、时长、字数、速度与合并正文。
4. 存在可行方案时点击 **下载修复后 SRT** 得到 `speed_fixed.srt`（从 1 连续重编号）；无可行方案时预览会指出**无法修复**及具体原因，下载按钮保持禁用。

修复与规划规则：

- **字数统计**：正文中每个**非空白字符**计一字（空格、制表符等不计）；
- **速度**：块速度 = 块内非空白字数 ÷ 块起止跨度（末条终点 − 首条起点），须 ≤ 最大每秒字数；块跨度同时须 ≤ 单块最长秒数，**两个限制须同时满足**（单条字幕自成一块时同样受限）；
- **输入校验**：任一条字幕出现**空时长**（终点 = 起点）、**起止倒置**（终点 < 起点）或**轨内重叠**（前条终点 > 后条起点）都会报错并指明位置；
- **合并限制**：仅允许合并**时间相邻且间隔 ≤ 500ms** 的连续字幕（间隔更大处必须切开）；合并块沿用**首条起点、末条终点**，正文按原顺序**换行拼接**；
- **全局规划**：以**合并次数最少**（= 条数 − 块数）为先；仍并列时选择**切分位置序列字典序最小**的方案（切分位置 = 相邻两条之间的切开处，按条目序号升序）；
- **无法修复**：若不存在满足全部限制的分块方案（例如某条自身时长已超单块上限，或尽量合并后速度仍超限），预览返回 `feasible: false` 与原因，导出接口返回 `400`。

实现上复用同一套 SRT 解析与导出格式；规划采用后缀动态规划（`plan_speed_fix`），利用「终点严格递增 ⇒ 块跨度随块尾单调」提前剪枝。

### 功能五：SRT 修订差异对照

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**SRT 修订差异对照**」区块（锚点 `#diff`，与上方四个功能相互独立，使用自己的旧版 / 新版输入框）。

1. 在「旧版 SRT」「新版 SRT」两个输入框中分别**粘贴** SRT 文本，或点击各自的「选择文件」上传 `.srt`。
2. 点击 **预览差异对照**：结果按**对齐组**展示，每组同时列出旧版与新版各条字幕的**原序号、时间、正文**，并用彩色标签区分六种类型：
   - **未变**：1:1 匹配，去空白与标点后正文完全相同（仅时间或标点差异也算未变）；
   - **改词**：1:1 匹配但正文有改动；
   - **拆分**：旧版 1 条对应新版 2 条；
   - **合并**：旧版 2 条对应新版 1 条；
   - **删除**：仅旧版存在（新版缺失）；
   - **新增**：仅新版存在（旧版缺失）。
3. 点击 **下载 UTF-8 CSV** 得到 `srt_diff.csv`（带 UTF-8 BOM，Excel 直接打开中文不乱码），每个对齐组一行，含组号、差异类型、相似度、时间差与双方原序号 / 时间 / 正文。

对齐与判定规则：

- **复用同一套解析器**（`parse_srt`）解析两版 SRT，保留各自文件中的原序号；
- 在**保持两版原有顺序**的前提下做**全局动态规划**对齐，每个对齐组只允许 **1:1、1:2（拆分）、2:1（合并）** 三种匹配以及**单侧跳过**（删除 / 新增）；
- 相似度基于**去除全部空白与标点、并做小写化（全角转半角）**后的正文，用序列匹配比率（0～1）计算；多对一组按组内各条正文**拼接后整体**计算，只有相似度 **≥ 0.5** 的组合才允许匹配；
- 全局目标：先**最大化所有匹配组的相似度总和**；总分相同时，再**最小化所有匹配组的时间差总和**（每组时间差取两侧字幕时间区间中点之差的毫秒数）；单侧跳过不计分，因此只有在确实不存在更优匹配时才会判为删除 / 新增；
- 拆分、合并组**按整段对照**（旧 1 段对新 2 段 / 旧 2 段对新 1 段的整体相似度达标即可），不会把拆分或合并后的段落逐条对撞而误报成改词、删除或新增；若拆并同时伴随正文改动，预览会额外标注「正文同时有改动」；
- **输入校验**：任一版 SRT 无法解析，或任一条字幕出现**空时长**（终点 = 起点）、**起止时间倒置**（终点 < 起点），都会返回明确错误并指明是哪一版第几条；两版条目数乘积超过对齐计算上限时也会报错提示。

实现上，`align_diff` 以三行滚动的保序网格 DP 求解五种转移，相似度定点化为整数后与时间差编码进同一整数目标（相似度位严格优先），回溯即可得到全部对齐组。

### 功能六：字幕目标词时间标记

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**字幕目标词时间标记**」区块（锚点 `#wordmark`，与上方五个功能相互独立，使用自己的 SRT / 目标词输入框）。

1. 在左侧粘贴 SRT 文本或点击「选择文件」上传 `.srt`，在右侧**逐行填写目标词**（每行一个）。
2. 可设置非负的**向前扩展毫秒**与**向后扩展毫秒**（默认均为 0）。
3. 点击 **预览命中**：先逐处列出每个命中的目标词、估算时间区间与原字幕序号（跨块命中带「跨块」标记），再列出扩展并合并后的区间；未命中的目标词单独列出。
4. 点击 **下载合并区间 CSV** 得到 `word_mark_intervals.csv`（带 UTF-8 BOM，Excel 直接打开中文不乱码），每行一个合并区间，含序号、起 / 终点毫秒、时长毫秒、起 / 终点 `HH:MM:SS,mmm`、命中词、原字幕序号与命中次数。无任何命中时禁止下载。

匹配与区间规则：

- **字符流**：按字幕原顺序连接各条字幕正文的**非空白字符**（空白不占时长份额）；目标词也去除行内全部空白后，做**大小写敏感的字面匹配**（允许相互重叠的命中，如 `aa` 在 `aaa` 中命中两次）；
- **跨块限制**：只有命中跨度内**每一对相邻字幕的间隔**（后条起点 − 前条终点）**≤ 500ms** 时才允许跨块命中；间隔更大的跨块出现被忽略（块内命中不受此限制）；
- **时间估算**：每个非空白字符按其**所在字幕时长等分**为等长子区间，命中区间取**首字符子区间的外侧起点**与**末字符子区间的外侧终点**（跨块时不补中间间隔）；
- **扩展与合并**：对每个命中区间向前 / 后扩展设定毫秒（均须为非负数）；扩展后起点小于 0 时**截为 0**（终点不截）；**重叠或端点相接**的扩展区间合并为一段，段内去重收集命中词与原字幕序号；
- **输入校验**：目标词全为空时报错；任一条字幕出现**空时长**（终点 = 起点）、**起止倒置**（终点 < 起点）或**轨内重叠**（前条终点 > 后条起点）都会返回明确错误并指明位置。

实现上复用同一套 SRT 解析（`parse_srt`）、时间格式化（`fmt_time`）与轨道校验（`_validate_speed_track`）；命中查找由 `find_word_hits` 完成（子串扫描 + 相邻间隔检查），扩展与合并由 `merge_hit_intervals` 按起点排序单趟合并。

### 功能七：字幕遮挡避让

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**字幕遮挡避让**」区块（锚点 `#position`，与上方六个功能相互独立，使用自己的 SRT 输入框）。

1. **粘贴** SRT 文本或点击「选择文件」上传 `.srt`。
2. 填写 1 个或多个**遮挡区间**（`HH:MM:SS,mmm`），每行选择遮挡一侧为**上方**或**下方**：
   - 每个区间**起点须早于终点**；**同侧区间允许重叠**（两侧区间互相独立，互不影响）；
   - 区间为**左闭右开** `[起点, 终点)`，字幕区间同样按左闭右开处理，端点相触（前段终点 = 后段起点）不算交叠。
3. 点击 **预览字幕位置**：逐条显示原序号、时间、正文、可选侧（被遮挡一侧划灰标注）、选定侧（上方 / 下方及对应 `line` 值）与**累计换位数**。
4. 点击 **下载 WebVTT** 得到 `positioned.vtt`；若有字幕两侧均被遮挡，预览会逐条列出其**原序号、时间与上 / 下两侧冲突区间**，下载按钮保持禁用。

遮挡判定与选侧规则：

- 字幕与遮挡区间按**左闭右开求正时长交叠**（`max(起点) < min(终点)`）；只要与同侧任一区间有正时长交叠，该侧即**不可放置**；
- 某条字幕**上、下两侧均被遮挡**时无解，预览返回 `feasible: false` 并指出每条冲突字幕的原序号（SRT 文件中的序号）与两侧冲突区间，导出接口返回 `400`；
- **输入校验**：至少 1 个遮挡区间；区间时间无法解析、起点不早于终点、遮挡一侧不是「上方 / 下方」都会报错并指明行号；SRT 无法解析、任一条字幕**空时长**（终点 = 起点）、**起止倒置**（终点 < 起点）或**轨内重叠**（前条终点 > 后条起点）同样报错；
- **动态规划目标**（对起止有效、按时间排列且互不重叠的字幕逐条选上方 / 下方）依次为：
  1. **最小化相邻字幕换位次数**（相邻两条选侧不同即一次换位）；
  2. 换位次数相同时，**最大化位于下方的条数**；
  3. 仍并列时，按**下方优先的位置序列**取舍（从上到下逐条比较选侧，首次不同处取下方）。

导出的 WebVTT 以 `WEBVTT` 开头、时间为 `HH:MM:SS.mmm`（点号分隔毫秒），**保留原正文与时间**，在每条时间行追加 cue 设置：上方为 `line:10%`、下方为 `line:90%`，cue 序号按原顺序从 1 连续编号。

实现上复用同一套 SRT 解析（`parse_srt`）、时间工具（`parse_time` / `fmt_time`）与轨道校验（`_validate_speed_track`）；选侧由 `plan_positions` 用逐位状态 DP 完成，状态按「换位数、负的下方条数、位置序列掩码」三元组比较，掩码把越早的字幕放在越高位、选下方置 1，一次回溯即得到满足三级目标的方案。

### 功能八：字幕章节索引

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**字幕章节索引**」区块（锚点 `#chapter`，与上方七个功能相互独立，使用自己的输入框）。

1. **粘贴** SRT 文本或点击「选择文件」上传 `.srt`。
2. 填写**目标、最短、最长章节时长**（秒）：均为**正数**且须满足 **最短 ≤ 目标 ≤ 最长**。
3. 点击 **预览章节切分**：逐章显示章号、起止时间、时长、条数、原序号范围、与目标偏差及首句。
4. 存在可行切分时点击 **下载章节索引 CSV** 得到 `chapters.csv`（带 UTF-8 BOM，Excel 直接打开中文不乱码）；无可行切分时预览给出具体原因，下载按钮保持禁用。

切分与规划规则：

- **切分方式**：只允许在**相邻字幕之间**切分，章节为连续字幕段并**覆盖全部字幕**；每章跨度 = 章内**首条起点 → 末条终点**，且必须落在 **[最短, 最长]** 范围内；
- **全局规划目标**（依次）：
  1. 各章跨度与目标时长的**绝对偏差之和最小**；
  2. 偏差之和并列时，**切点处字幕间隙**（后条起点 − 前条终点）**总时长最大**；
  3. 仍并列时，选择**切点序列字典序最小**的方案（切点 = 第 2 章起各章首条的位置，按条目顺序升序）；
- **首句**：取章内首个非空正文行；
- **输入校验**：三个时长均须为正数且满足 最短 ≤ 目标 ≤ 最长；任一条字幕出现**空时长**（终点 = 起点）、**起止倒置**（终点 < 起点）或**轨内重叠**（前条终点 > 后条起点）都会报错并指明位置；
- **无法切分**：若不存在使每章跨度都落在范围内的切分（例如某条自身时长已超最长章节、剩余字幕总跨度不足最短章节，或相邻两条之间的跨度从不足最短直接跳过最长），预览返回 `feasible: false` 与具体原因，导出接口返回 `400`。

实现上复用同一套 SRT 解析（`parse_srt`）与轨内时间校验（`_validate_speed_track`）；规划采用后缀动态规划（`plan_chapters`），利用「终点严格递增 ⇒ 章节跨度随章末单调」提前剪枝，三级目标编码为元组逐状态比较，一次回溯得到切分方案。

### 功能九：字幕空隙提示编排

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**字幕空隙提示编排**」区块（锚点 `#hint`，与上方八个功能相互独立，使用自己的输入框）。

1. 在左侧**粘贴** SRT 文本或点击「选择文件」上传 `.srt`。
2. 在右侧**逐行填写提示**，每行三段（以空白分隔）：`目标起点 持续毫秒 正文`，例如 `00:00:05,000 1500 请注意画面`；空行自动跳过。
3. 点击 **预览编排结果**：分别列出**已放入**提示（提示行号、目标起点、实际时间、偏差毫秒、所在空隙、正文）、**未放入**提示，以及全部**正时长空隙**（相邻原序号、时间范围、时长、是否已用）。
4. 点击 **下载编排后 SRT** 得到 `hinted.srt`：原字幕与已放入提示按时间排序后**从 1 连续重编号**，原字幕的正文与时间**原样保留**；未放入的提示不写入导出文件（没有提示被放入时仍可下载，导出文件即重编号后的原字幕）。

编排与匹配规则：

- **空隙**：仅使用**相邻原字幕之间的正时长空隙**（后条起点 − 前条终点 > 0；端点相触不算空隙），每个空隙**最多放入一条**提示；首条之前、末条之后的区域不使用；
- **提示排序**：提示先按**目标起点**、再按**输入行号**排序，排序后与空隙做**保序全局匹配**（第 k 条被放入的提示使用第 k 个被占用的空隙）；
- **实际起点**：提示可放入某空隙当且仅当**空隙时长 ≥ 持续毫秒**；实际起点把目标起点**夹到** `[空隙起点, 空隙终点 − 持续毫秒]` 范围，偏差 = |实际起点 − 目标起点|；放入的提示不与原字幕重叠，原字幕时间不变；
- **全局目标**（依次）：
  1. **放入条数最多**；
  2. 条数并列时，**已放入提示的偏差之和最小**；
  3. 仍并列时，**已用空隙序号（1 起，升序）序列字典序最小**；
- **输入校验**：提示行**时间无法解析**、**持续毫秒非正整数**、**正文为空**（含只有两段）都会报错并指明输入行号；全部行为空时报错；SRT 无法解析、任一条字幕**空时长**（终点 = 起点）、**起止倒置**（终点 < 起点）或**轨内重叠**（前条终点 > 后条起点）同样报错；提示条数 × 空隙数超过匹配计算上限时报错提示。

实现上复用同一套 SRT 解析（`parse_srt`）、时间工具（`parse_time` / `fmt_time`）与轨道校验（`_validate_speed_track`）；匹配由 `plan_hint_placement` 的保序网格 DP 完成，三级目标与双语合成同样编码为单个整数权重（条数位 | 偏差位 | 空隙序号位掩码），一次回溯得到编排方案。

### 功能十：角色抢话分析

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**角色抢话分析**」区块（锚点 `#talkover`，与上方九个功能相互独立，使用自己的输入框）。

1. **粘贴**带角色标记的 SRT 文本或点击「选择文件」上传 `.srt`：每条字幕正文**首行须以 `[角色名]` 开头**（如 `[Alice] 你好`），标记须位于首行最开头；后续行可写普通台词。
2. 点击 **预览抢话分析**：依次列出每个抢话片段（序号、起止 `HH:MM:SS,mmm`、毫秒、时长、同时发言角色），并汇总**每名角色独占时长**与**每对角色共同发言时长**。
3. 点击 **下载抢话分析 CSV** 得到 `talkover.csv`（带 UTF-8 BOM，Excel 直接打开中文不乱码），文件分三段：抢话片段、每名角色独占时长、每对角色共同发言时长。

标记与分析规则：

- **角色标记**：正文首行以 `[角色名]` 开头，角色名**去首尾空白**后**同名合并**（`[ Bob ]` 与 `[Bob]` 视为同一角色）；
- **拒绝分析**：任一条字幕正文为空、首行缺失 `[角色名]` 标记，或标记中角色名去空白后为空，都会报错并**逐条指出原字幕序号**（文件中的序号），不进行分析；
- **区间并集**：先把同一角色的全部字幕时间按**左闭右开** `[起点, 终点)` 求并集（同一角色端点相触的两条字幕合并为一段连续区间，重叠区间同样合并；空时长 / 倒置区间不占时间轴）；
- **时间轴切分**：再以各角色并集的全部起点 / 终点为边界切分时间轴，逐段计算活跃角色集合；同一时刻的事件先结算区间再变更集合，因此**端点相触不算同时活跃**；
- **抢话片段**：仅有**两名及以上角色同时活跃**的片段计入抢话；**相邻且活跃角色集合相同**的片段自动合并为一段（活跃集合不同的相邻片段保持分开，如 `AB → ABC → AB` 计为 3 段）；
- **独占时长**：某段时间内只有该角色一人活跃的毫秒数合计；
- **共同发言时长**：两名角色同时活跃的毫秒数合计（此时若有第三人在场也照常计入，因此各对时长之和可能大于抢话片段总时长）；角色对按角色首次出现顺序全部列出（含 0 毫秒对）；
- 即使没有任何抢话片段，只要角色标记校验通过即可下载 CSV（片段段为空，汇总照常输出）。

实现上复用同一套 SRT 解析（`parse_srt`）与时间工具（`parse_time` / `fmt_time`）；核心逻辑由 `analyze_talkover` 完成（同角色区间并集 + 边界事件扫描线 + 活跃集合片段合并）。

### 功能十一：术语统一替换

页面入口：打开 **http://localhost:8000** 后滚动到页面底部的「**术语统一替换**」区块（锚点 `#terms`，与上方十个功能相互独立，使用自己的输入框）。

1. 在左侧**粘贴** SRT 文本或点击「选择文件」上传 `.srt`。
2. 在右侧**逐行录入术语**，每行格式为 `标准词=别名1|别名2`（如 `人工智能=AI|ai`），空行自动跳过：
   - 标准词与每个别名去首尾空白后**均不能为空**；
   - 同一别名（**忽略 ASCII 大小写**）**不能对应不同标准词**；同一标准词重复登记同一别名会自动去重。
3. 点击 **预览替换结果**：逐条显示原序号、时间、原文、全部命中（字符偏移、命中词、别名、所属术语行、采用 / 舍弃）与修订正文（替换处高亮标出）。
4. 点击 **下载修订 SRT** 得到 `terms_replaced.srt`：**保留原序号与原时间**，正文为修订后内容；**没有任何命中时也可下载**，内容即原样字幕。

匹配与规划规则：

- **一次性匹配**：对每条字幕的**原正文**（多行按换行连接）一次性查找全部别名，匹配**忽略 ASCII 大小写**（仅 A–Z / a–z，非 ASCII 字符按原样比较），允许相互重叠的命中（如 `aa` 在 `aaa` 中命中两次）；命中全部在原文上定位，规划确定后一次性改写，**不会边替换边继续匹配**（修订文本不再参与匹配）；
- **全局规划**：同条字幕内的重叠命中用动态规划选择互不重叠的采用组合，目标依次为：
  1. **被替换的原文字符数最多**；
  2. 字符数并列时，**替换次数最少**；
  3. 仍并列时，**采用命中的起点序列（升序）字典序最小**；
  4. 完全并列（同一跨度命中不同术语）时，按**术语登记顺序**取先者（确定性兜底）；
- **命中位置**：预览中的位置为每条字幕正文（多行按换行连接后）的字符偏移，左闭右开；
- **输入校验**：术语行缺少 `=`、标准词为空、别名为空、同一别名对应不同标准词、术语全部为空，或 SRT 无法解析，都会返回明确错误并指明行号；
- **下载**：保留原序号与原时间，仅改写正文；无命中时照常下载（内容与原字幕一致）。

实现上复用同一套 SRT 解析（`parse_srt`）与时间格式化（`fmt_time`）；术语解析由 `_parse_term_lines` 完成，命中查找由 `find_term_hits` 完成（归一化 ASCII 大小写后的子串扫描），替换规划由 `plan_term_replacements` 的按字符位置后缀 DP 完成（三级目标编码为元组逐状态比较，一次回溯得到采用组合）。

## 规则说明

### 锚点校验（不满足会被拒绝并提示）

- 至少 2 个锚点；
- 原时刻不得重复；
- 映射后的实际时刻必须严格递增。

### 锚点异常定位（剔除建议）

锚点校验失败时，后端按以下规则求一个修复方案：

1. 将锚点按**原时刻**排序，选出原时刻与实际时刻**都严格递增**的最长子序列（至少含 2 点），即需要剔除的锚点最少；
2. 多解时先最大化**首/尾原时刻**（全局最小、最大原时刻）锚点的保留数量；
3. 仍多解时，按待剔除项的**原输入行号序列**字典序最小决胜；
4. 无法解析的时间格式行必然在剔除之列；有效锚点不足 2 点则返回「无法预演」。

该逻辑由 `POST /api/suggest` 提供，返回剔除行号、逐行原因，并用保留锚点复用校准预览展示受影响字幕。

### 问题检测（存在任一问题时禁止导出）

| 问题 | 判定 |
| --- | --- |
| 负时间 | 校准后起点或终点 < 0 |
| 起止倒置 | 校准后终点 ≤ 起点 |
| 与下一条重叠 | 本条终点 > 下一条起点 |

前端预览会标红问题行，后端导出接口同样强制校验，有问题返回 400。

## API

校准功能：

- `POST /api/preview` — 请求体 `{"srt": "...", "anchors": [{"orig": "00:01:00,000", "actual": "00:01:02,500"}, ...]}`，返回逐条校准结果与问题标记。锚点校验失败返回 `400`，`detail` 为 `{"type": "anchor_invalid", "message": "..."}`。
- `POST /api/suggest` — 同请求体；锚点校验失败时的异常定位建议。
  - 可行时返回：`feasible: true`、`remove_rows`（建议剔除的输入行号，1 起）、`kept`（保留锚点）、`removed`（逐行剔除原因）、`preview`（用保留锚点得到的校准预览，结构同 `/api/preview`）或 `preview_error`（SRT 无法解析时）。
  - 不可行时返回：`feasible: false` 与 `reason`（无法预演原因）。
- `POST /api/export` — 同 `/api/preview` 请求体；无问题时返回 `calibrated.srt` 文件下载，有问题返回 `400`。

剪辑功能（独立 API，复用同一套 SRT 解析与时间格式化）：

- `POST /api/clip/preview` — 请求体 `{"srt": "...", "intervals": [{"start": "00:01:00,000", "end": "00:02:00,000"}, ...]}`；返回 `interval_count`、`total_duration`（拼接后总时长）、`entry_count` 与逐条结果（新序号、原序号、交集原时间、剪辑后时间、正文）。区间为空 / 起点不早于终点 / 解析失败 / 区间重叠时返回 `400`。
- `POST /api/clip/export` — 同请求体；返回按新起点排序并连续重编号的 `clipped.srt` 文件下载；无任何字幕落入保留区间时返回 `400`。

双语合成功能（独立 API，复用同一套 SRT 解析与时间格式化）：

- `POST /api/merge/preview` — 请求体 `{"main": "...", "translation": "..."}`（均为完整 SRT）。返回 `main_count`、`trans_count`、`matched_count`、`unmatched_count`、`total_overlap_ms` / `total_overlap`（最优总交叠）、逐条 `entries`（主轨序号/原序号/时间/正文及其 `translations`，每条译文带原序号、时间、交叠毫秒数与正文）以及 `unmatched`（未配对译文）。任一轨 SRT 无法解析、出现空时长或起止倒置时返回 `400`。
- `POST /api/merge/export` — 同请求体；按主轨时间与顺序从 1 连续编号，主轨正文与各配对译文正文分行写入，返回 `bilingual.srt` 文件下载（主轨无译文仍保留）。校验规则同上，失败返回 `400`。

阅读速度修复功能（独立 API，复用同一套 SRT 解析与导出格式）：

- `POST /api/speed/preview` — 请求体 `{"srt": "...", "max_cps": 20.0, "max_block_seconds": 7.0}`（两个参数均须为正数）。返回 `feasible`、`entry_count`、`block_count`、`merge_count`（合并次数）与逐块 `blocks`（新序号 `seq`、来源原序号 `sources`、起止时间、`duration_ms`、非空白字数 `chars`、速度 `cps`、合并正文 `text`）；无可行方案时返回 `feasible: false` 与 `reason`（无法修复原因）。参数非正数、SRT 无法解析、空时长 / 起止倒置 / 轨内重叠时返回 `400`。
- `POST /api/speed/export` — 同请求体；返回从 1 连续重编号的 `speed_fixed.srt` 文件下载（合并块沿用首条起点、末条终点，正文按原顺序换行拼接）；无可行方案时返回 `400` 并附无法修复原因。

修订差异对照功能（独立 API，复用同一套 SRT 解析与时间格式化）：

- `POST /api/diff/preview` — 请求体 `{"old_srt": "...", "new_srt": "..."}`（均为完整 SRT）。返回 `old_count`、`new_count`、`group_count`、`counts`（六种类型的组数统计）、`matched_group_count`、`total_similarity` / `avg_similarity`，以及逐组 `groups`：`seq`（组号）、`type`（`unchanged` / `changed` / `split` / `merge` / `delete` / `add`）、`old` 与 `new`（双方各条的顺序号、SRT 原序号 `index`、时间、正文），匹配组另附 `similarity`、`gap_ms`（中点时间差毫秒）与 `text_changed`（拆分 / 合并组正文是否同时有改动）。任一版 SRT 无法解析、出现空时长或起止倒置、对齐规模超限时返回 `400`。
- `POST /api/diff/export` — 同请求体；返回带 UTF-8 BOM 的 `srt_diff.csv` 文件下载（RFC 4180 转义，字段为：组号、差异类型、相似度、时间差(ms)、旧版序号、旧版时间、旧版正文、新版序号、新版时间、新版正文）。校验规则同上，失败返回 `400`。

目标词时间标记功能（独立 API，复用同一套 SRT 解析、时间格式化与轨道校验）：

- `POST /api/wordmark/preview` — 请求体 `{"srt": "...", "words": "world\nfoobar", "pre_ms": 0, "post_ms": 0}`，`words` 为逐行目标词（行内空白忽略、空行跳过），`pre_ms` / `post_ms` 为非负的前 / 后扩展毫秒。返回 `entry_count`、`word_count`、`hit_count`、`segment_count`、逐处 `hits`（目标词行号 `row`、命中词、估算起止 `start`/`end` 与毫秒、`cross_block` 是否跨块、原字幕序号 `indices`）、扩展合并后的 `segments`（序号、起止毫秒与格式化时间、时长毫秒、命中词、原字幕序号、命中次数）以及未命中目标词 `unmatched`。参数为负、目标词全空、SRT 无法解析、空时长 / 起止倒置 / 轨内重叠时返回 `400`。
- `POST /api/wordmark/export` — 同请求体；返回带 UTF-8 BOM 的 `word_mark_intervals.csv` 文件下载（RFC 4180 转义，字段为：序号、起点(ms)、终点(ms)、时长(ms)、起点、终点、命中词、原字幕序号、命中次数）。无任何命中时返回 `400`。

字幕遮挡避让功能（独立 API，复用同一套 SRT 解析、时间格式化与轨道校验）：

- `POST /api/position/preview` — 请求体 `{"srt": "...", "intervals": [{"start": "00:01:00,000", "end": "00:02:00,000", "side": "top"}, ...]}`，`side` 为 `top`（上方遮挡）或 `bottom`（下方遮挡），同侧区间允许重叠。可行时返回 `feasible: true`、`entry_count`、`interval_count`、`switch_count`（相邻换位总次数）、`top_count` / `bottom_count` 与逐条 `entries`（顺序号 `seq`、SRT 原序号 `index`、时间、正文、选定侧 `side`、`available` 两侧是否可选、`blocked` 两侧命中的遮挡区间（含输入行号、起止时间与毫秒）、截至本条的累计换位数 `switches`）。存在两侧均被遮挡的字幕时返回 `feasible: false` 与 `conflicts`（逐条顺序号、原序号、时间、正文及上 / 下两侧冲突区间）。区间为空 / 时间无法解析 / 起点不早于终点 / 侧别非法 / SRT 无法解析 / 空时长 / 起止倒置 / 轨内重叠时返回 `400`。
- `POST /api/position/export` — 同请求体；返回 `positioned.vtt`（WebVTT：`WEBVTT` 头、`HH:MM:SS.mmm` 时间，保留原正文与时间，上方 / 下方分别在时间行追加 `line:10%` / `line:90%`）。存在两侧均被遮挡的字幕或校验失败时返回 `400` 并指明冲突字幕。

字幕章节索引功能（独立 API，复用同一套 SRT 解析与轨道校验）：

- `POST /api/chapter/preview` — 请求体 `{"srt": "...", "target_seconds": 600, "min_seconds": 300, "max_seconds": 900}`（三个时长均为正数且 最短 ≤ 目标 ≤ 最长）。可行时返回 `feasible: true`、`entry_count`、`chapter_count`、`total_deviation_ms`（各章与目标时长的绝对偏差之和）、`total_gap_ms`（切点处字幕间隙总时长）、`cuts`（第 2 章起各章首条的 1 起位置）与逐章 `chapters`（章号 `seq`、起止时间与毫秒、`duration_ms`、`deviation_ms`、条数 `entry_count`、原序号范围 `first_index` / `last_index`、首句 `first_line`）；无可行切分时返回 `feasible: false` 与 `reason`（无法切分原因）。参数非正数或不满足 最短 ≤ 目标 ≤ 最长、SRT 无法解析、空时长 / 起止倒置 / 轨内重叠时返回 `400`。
- `POST /api/chapter/export` — 同请求体；返回带 UTF-8 BOM 的 `chapters.csv` 文件下载（RFC 4180 转义，字段为：章号、起点(ms)、终点(ms)、时长(ms)、起点、终点、字幕条数、首句）。无可行切分或校验失败时返回 `400` 并附原因。

字幕空隙提示编排功能（独立 API，复用同一套 SRT 解析、时间格式化与轨道校验）：

- `POST /api/hint/preview` — 请求体 `{"srt": "...", "hints": "00:00:05,000 1500 提示正文\n..."}`，`hints` 为逐行提示（每行「目标起点 持续毫秒 正文」三段，空白分隔，空行跳过）。返回 `entry_count`、`gap_count`、`hint_count`、`placed_count` / `unplaced_count`、`total_deviation_ms`（已放入提示的偏差之和）、逐空隙 `gaps`（序号 `seq`、起止时间与毫秒、`duration_ms`、相邻原序号 `prev_index` / `next_index`、是否已用 `used`）、逐条已放入 `placed`（提示输入行号 `row`、目标起点、实际起止时间与毫秒、`deviation_ms`、所在空隙 `gap`、正文）以及未放入 `unplaced`（行号、目标起点、持续毫秒、正文）。提示行时间非法 / 持续毫秒非正整数 / 正文为空、提示全空、SRT 无法解析、空时长 / 起止倒置 / 轨内重叠、匹配规模超限时返回 `400`。
- `POST /api/hint/export` — 同请求体；返回 `hinted.srt` 文件下载：原字幕与已放入提示按时间排序后从 1 连续重编号，原字幕正文与时间原样保留，未放入的提示不写入。校验规则同上，失败返回 `400`。

角色抢话分析功能（独立 API，复用同一套 SRT 解析与时间格式化）：

- `POST /api/talkover/preview` — 请求体 `{"srt": "..."}`，每条字幕正文首行须以 `[角色名]` 开头，角色名去首尾空白后同名合并。返回 `entry_count`、`role_count`、`roles`（按首次出现顺序）、`overlap_count` 与 `overlap_total_ms`、逐片段 `overlaps`（序号 `seq`、起止时间与毫秒、`duration_ms`、同时发言角色 `roles`），以及 `solo`（每名角色独占毫秒数与格式化时长）与 `pairs`（每对角色共同发言毫秒数与格式化时长，按首次出现顺序、含 0 毫秒对）。任一条字幕缺失角色标记或角色名为空时返回 `400`，`detail` 中逐条指出其原字幕序号。
- `POST /api/talkover/export` — 同请求体；返回带 UTF-8 BOM 的 `talkover.csv`（RFC 4180 转义），分三段：抢话片段（序号、起点(ms)、终点(ms)、时长(ms)、起点、终点、同时发言角色）、每名角色独占时长（角色、独占(ms)、独占时长）、每对角色共同发言时长（角色A、角色B、共同发言(ms)、共同发言时长）。角色标记校验失败时返回 `400`；无抢话片段时仍可下载（片段段为空，汇总照常输出）。

术语统一替换功能（独立 API，复用同一套 SRT 解析与时间格式化）：

- `POST /api/terms/preview` — 请求体 `{"srt": "...", "terms": "标准词=别名1|别名2\n..."}`，`terms` 为逐行术语（空行跳过；标准词与每个别名均不能为空；同一别名忽略 ASCII 大小写不得对应不同标准词）。返回 `entry_count`、`term_count`、`alias_count`（去重后别名数）、`hit_count`、`adopted_count` / `discarded_count`、`changed_count`（有改动的字幕条数）与逐条 `entries`：顺序号 `seq`、SRT 原序号 `index`、时间、原文 `text`、修订正文 `revised`、是否改动 `changed`、修订分段 `segments`（替换处 `rep: true`，供高亮）及全部命中 `hits`（起止字符偏移 `start` / `end`、命中词 `surface`、别名 `alias`、标准词 `std`、术语行号 `row`、是否采用 `adopted`）。术语格式非法、别名为空、别名冲突、SRT 无法解析时返回 `400`。
- `POST /api/terms/export` — 同请求体；返回保留原序号与时间的 `terms_replaced.srt` 文件下载（无命中时内容与原字幕一致，照常下载）。校验规则同上，失败返回 `400`。
