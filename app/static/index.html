剪辑片段字幕

按原视频时间填写多个保留区间（左闭右开，格式 HH:MM:SS,mmm）。 每条字幕与各区间求交集：无交集的丢弃，跨区间的字幕拆成多条并保留正文； 每段交集时间减去该区间起点、再累加此前区间总时长，得到剪辑后连续时间轴。 区间起点须早于终点，按起点排序，重叠将被拒绝。

双语 SRT 合成

阅读速度修复

粘贴或上传 SRT，设置最大每秒字数与单块最长秒数（均为正数）。 非空白字符各计一字，速度按每块起止跨度（首条起点 → 末条终点）计算； 空时长、起止倒置或轨内重叠会直接报错。仅允许合并时间相邻且间隔 ≤ 500ms 的连续字幕， 合并块沿用首条起点、末条终点，正文按原顺序换行拼接；每块须同时满足速度与最长时长限制。 全局规划以合并次数最少为先，仍并列时选择切分位置序列字典序最小的方案； 无可行方案时会指出无法修复。确认预览后下载从 1 连续重编号的 SRT。

SRT 修订差异对照

分别粘贴或上传旧版与新版两份 SRT，自动按顺序对齐两版字幕并逐组对照。 对齐在保持原有顺序的前提下做全局动态规划，每组允许 1:1（改词/未变）、1:2（拆分）、2:1（合并）以及单侧跳过（删除/新增）。 相似度基于去除空白与标点并小写化后的正文计算，只有相似度 ≥ 0.5 的组合才允许匹配； 全局优先最大化相似度总和，总分相同时选择时间差总和更小的方案。 拆分组与合并组按整段对照，不会把拆分/合并后的段落误报成改词或删除/新增。

字幕目标词时间标记

粘贴一份 SRT 与逐行目标词（每行一个，行内空白自动忽略）， 按字幕原顺序把正文的非空白字符连接成字符流，对每个目标词做大小写敏感的字面匹配（允许重叠命中）。 仅当命中跨越相邻字幕、且沿途每对相邻字幕间隔 ≤ 500ms 时才允许跨块； 每个字符按所在字幕时长等分，命中区间取首字符子区间的外侧起点与末字符子区间的外侧终点。 可设置非负的前 / 后扩展毫秒：扩展后起点小于 0 截为 0，重叠或端点相接的区间合并。 字幕出现空时长、起止倒置或轨内重叠会直接报错。确认预览后可下载合并区间 CSV。

字幕遮挡避让

粘贴 SRT 并填写若干遮挡区间（起止时刻 HH:MM:SS,mmm 与遮挡一侧：上方 / 下方）。 字幕与遮挡区间按左闭右开求正时长交叠（端点相触不算），交叠的一侧不可放置； 同侧区间允许重叠，每个区间起点须早于终点。对起止有效、按时间排列且互不重叠的字幕，逐条选上方或下方，动态规划依次 最小化相邻字幕换位次数、最大化位于下方的条数，仍并列时按下方优先的位置序列取舍。 某条字幕两侧均被遮挡时会指出其原序号与冲突区间并禁止下载。预览显示每条可选侧、选定侧与累计换位数； 导出的 WebVTT 保留正文与时间，以 line:10% / line:90% 标示上方 / 下方。

字幕章节索引

粘贴或上传 SRT，填写目标、最短、最长章节时长（秒，均为正数且 最短 ≤ 目标 ≤ 最长）。 只允许在相邻字幕之间切分，章节覆盖全部字幕；每章跨度为章内首条起点 → 末条终点，且必须落在最短 / 最长范围内。 全局规划依次使各章与目标时长的绝对偏差之和最小、切点处字幕间隙总时长最大，仍并列时取切点序列字典序最小的方案； 无可行切分时给出原因并禁止下载。字幕出现空时长、起止倒置或轨内重叠会直接报错。预览每章起止、条数与首句，确认后可下载 UTF-8 CSV 章节索引。

字幕空隙提示编排

粘贴或上传 SRT，并逐行填写提示（每行三段：目标起点 持续毫秒 正文，以空白分隔，如 00:00:05,000 1500 请注意画面）。 只使用相邻原字幕之间的正时长空隙，每个空隙最多放入一条提示；提示按目标起点、输入行号排序后与空隙做有序全局匹配： 先最大化放入条数，再最小化实际起点与目标起点的绝对偏差之和（每条提示的实际起点在候选空隙内夹到可用范围），仍并列时取空隙序号序列字典序最小的方案。 放入的提示不与原字幕重叠，原字幕时间保持不变。SRT 出现空时长、起止倒置或轨内重叠，或提示行时间非法、持续毫秒非正整数、正文为空都会报错。 预览显示已放入位置、偏差与未放入提示，确认后可下载按时间重编号的 SRT（原字幕正文与时间原样保留）。

角色抢话分析

粘贴一份带角色标记的 SRT：每条字幕正文首行须以 [角色名] 开头 （如 [Alice] 你好），角色名去首尾空白后同名合并；缺失标记或角色名为空时会指出原字幕序号并拒绝分析。 先把同一角色的字幕时间按左闭右开区间求并集，再按各角色并集边界切分时间轴： 只有两名及以上角色同时活跃的片段计入抢话（端点相触不算），相邻且活跃角色集合相同的片段自动合并。 预览列出每个抢话片段及其角色，并汇总每名角色的独占毫秒数与每对角色的共同发言毫秒数；可下载包含片段与汇总的 UTF-8 CSV。

术语统一替换

粘贴或上传 SRT，并逐行录入术语（每行 标准词=别名1|别名2，如 人工智能=AI|ai）。 标准词与每个别名均不能为空；同一别名（忽略 ASCII 大小写）不能对应不同标准词，重复登记同一标准词会自动去重。 对每条字幕的原正文一次性查找全部别名：匹配忽略 ASCII 大小写（非 ASCII 字符按原样比较）、允许重叠命中， 命中全部在原文上定位，不会边替换边继续匹配。同条字幕的重叠命中用全局规划选择互不重叠的组合： 依次使被替换的原文字符数最多、替换次数最少、采用命中起点序列字典序最小。 预览逐条显示原文、命中位置（字符偏移）、采用与舍弃的命中及修订正文（替换处高亮）； 下载的 SRT 保留原序号与时间，没有任何命中时也可下载原样内容。
